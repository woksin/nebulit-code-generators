### Generated Command, Event, and Rules (AddBook.cs)

All command-related code is in a single file:

```csharp
namespace Library.Inventory.AddBook;

/// <summary>
/// Represents the command to AddBook.
/// </summary>
/// <param name="string Title, string ISBN, Guid AuthorId">The command parameters.</param>
[Command]
public record AddBook(string Title, string ISBN, Guid AuthorId)
{
    /// <summary>
    /// Handles the command and returns the resulting event.
    /// </summary>
    /// <returns>The BookAdded event.</returns>
    public BookAdded Handle() => new(Title, ISBN, AuthorId);
}

/// <summary>
/// Represents the event that is raised when BookAdded.
/// </summary>
/// <param name="string Title, string ISBN, Guid AuthorId">The event data.</param>
[EventType]
public record BookAdded(string Title, string ISBN, Guid AuthorId);

/// <summary>
/// Represents the validation rules for AddBook.
/// </summary>
public class AddBookRules : AbstractValidator<AddBook>
{
    /// <summary>
    /// Initializes a new instance of the <AddBookRules> class.
    /// </summary>
    public AddBookRules()
    {
        RuleFor(cmd => cmd.Title).NotEmpty();
        RuleFor(cmd => cmd.ISBN).NotEmpty();
        RuleFor(cmd => cmd.AuthorId).NotEmpty();
    }
}
```

### Generated Read Model (Books.cs)
```csharp
namespace Library.Inventory.AddBook;

public record Books(string ISBN, string Title);

public class BooksProjection : IProjectionFor<Books>
{
    public void Define(IProjectionBuilderFor<Books> builder)
    {
        builder.AutoMap()
            .From<BookAdded>();
    }
}

[Route("/api/addbook")]
public class BooksQueries(IMongoCollection<Books> collection) : ControllerBase
{
    [HttpGet]
    public async Task<IEnumerable<Books>> GetAll()
    {
        var result = await collection.FindAsync(_ => true);
        return result.ToList();
    }

    [HttpGet("observe")]
    public ISubject<IEnumerable<Books>> ObserveAll() =>
        collection.Observe();
}
```

## Running the Generated Application

1. **Start Chronicle Server**:
   ```bash
   docker-compose up -d
   ```

2. **Run the Application**:
   ```bash
   dotnet run
   ```

3. **Execute a Command** (via Swagger at https://localhost:5001/swagger):
   - POST to the generated command endpoint
   - The command handler produces an event
   - Chronicle stores the event
   - The projection automatically updates the read model

4. **Query Read Models**:
   - GET `/api/addbook` - Returns all books
   - GET `/api/addbook/observe` - Real-time observable stream

5. **Run Tests**:
   ```bash
   dotnet test
   ```
